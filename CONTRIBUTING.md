# Contributing to SkyClock

Thanks for your interest in contributing!

## Before you start

- Check existing issues and pull requests to avoid duplicate work.
- For a substantial change, open an issue first to discuss the approach.

## Changes

- Keep changes focused and explain the motivation in your pull request.
- Add or update tests and documentation when appropriate.
- Run the project's relevant checks before submitting. (The project toolchain is not yet defined.)

## Pull requests

Include a summary, relevant issue links, and any testing performed. Be clear about known limitations or follow-up work.
